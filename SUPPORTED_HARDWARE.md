# Supported Hardware

Demonym was originally designed and developed for the M5Stack Cardputer ADV.

## Current Support

| Device                | Status    | Input             | Multiplayer |
| --------------------- | --------- | ----------------- | ----------- |
| M5Stack Cardputer ADV | Supported | Built-in keyboard | ESP-NOW     |

## Planned / Experimental Targets

Support for additional ESP32 devices is being investigated.

Potential ports may require changes to display, input, audio, storage, and device-specific hardware abstraction layers.
