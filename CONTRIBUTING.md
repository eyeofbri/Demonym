# Contributing

Demonym is still a personal project and I am keeping the full production source private for now.

I am happy to take issue reports for the public firmware, docs, and examples. Small pull requests for typos, broken links, or problems in the public examples are also fine.

For game code or larger feature ideas, an issue is better than a pull request right now since most of the real implementation lives in the private repo.

Please do not include private keys, credentials, personal device data, or somebody else's copyrighted assets in an issue or pull request.
