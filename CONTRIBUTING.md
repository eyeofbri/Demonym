# Contributing

Demonym's complete production firmware is currently developed in a private repository, so this public repository is not accepting feature pull requests against the full game source.

Useful public contributions may include:

- documentation corrections
- reproducible firmware-release bug reports
- hardware compatibility observations
- corrections to the public examples/tests

When reporting a firmware issue, include the Demonym version, exact ESP32 device, whether the build was an upgrade or clean flash, and clear reproduction steps. Do not post private keys, credentials, Wi-Fi passwords, or other sensitive device data.
